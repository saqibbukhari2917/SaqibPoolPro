# Saqib Finance

An offline-first Android family expense tracker.

- Record purchases in Kids, Wife, Family, Medicine, Grocery, Transport, Bills, Shopping, Dining and Other.
- Add a description, amount in PKR and purchase date.
- Edit or delete entries.
- Monthly totals and category-wise pie chart.
- Expenses are stored locally on the device with SQLite; no account or internet connection is required.

## Build
With Java 17 and Android SDK Platform 35 installed, run `gradle --no-daemon assembleDebug`.
APK output: `app/build/outputs/apk/debug/app-debug.apk`.
